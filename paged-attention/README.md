# PagedAttention 的上下游数据流

打开[交互图](index.html)，选择「首次 Prefill」或「跨页 Decode」。点击「下一步」可沿现有连线查看这一轮的 8 个步骤。「播放流程」支持暂停，「全局关系」可随时返回完整图。在「查看依赖」中选择写入或读取，可以单独查看该算子的上下游。

节点、连线编号与下方可点击的完整 8 步列表来自同一份步骤数据；切换 Prefill / Decode 时，列表同步显示对应的输入、输出和消费者。编号表示讲解次序，本地索引计算仍标在节点中。

示例中每块存放 128 个位置的 K/V。首次 Prefill 将位置 0 到 127 写进块 7。下一轮 Decode 处理位置 128，Scheduler 分配块 3，Worker 将块表从 `[7]` 更新为 `[7, 3]`。新 K/V 写到槽 `3 × 128 + 0 = 384`，当前 Q 根据完整块表和有效长度 129 读取两块中的有效位置。

图按 vLLM `295c062db8` 和 vLLM-Ascend `94e3e25f8` 的 V1 单卡源码绘制。示例采用普通 decoder full attention 和单 KV 组，块号为教学取值。图内「源码入口与示例条件」包含算子选路条件及对应源码链接。[可编辑图源](source.html)
