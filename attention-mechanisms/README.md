# 注意力机制逐步演算

用浏览器打开 [index.html](index.html)，选择机制，点「执行下一步」跟踪输入、中间值和输出。「自动执行」支持暂停并从同一帧继续。完整图上的每个步骤都可以点击重播。

| 想观察的计算 | 可选演示 |
| --- | --- |
| 一个查询如何得到输出，多个查询头如何读取 KV | 普通因果注意力、MHA、MQA、GQA |
| 哪些历史位置参与本次计算 | SWA、StreamingLLM、Block-Sparse |
| KV 怎样分块计算或分页寻址 | FlashAttention、PagedAttention |
| 状态怎样跨 token 更新，再传给下一层 | SSM 混合架构、KDA |
| 如何压缩 KV、加入位置信息、筛选历史记录 | MLA、DSA、DeepSeek V4 的 CSA 与 HCA |
| 如何跨层共享 KV，在候选池内重选或沿用位置 | DeepSeek V4.1 的 CSA2，含 Full、Reindex 与 Reuse |

例如，选择 PagedAttention，把跟踪位置设为 `t₄`。每页存两个 token，其零基位置 3 对应逻辑块 1、偏移 1。块表将逻辑块 1 映射到物理块 2，最终从槽 `2 × 2 + 1 = 5` 读出 K 和 V。下一步可以看到当前查询如何给四个位置分配权重。

图内矩阵、窗口和块大小采用可手算的教学值。每幅图下方附有对应论文或模型配置。[可编辑图源](source.html)

CSA2 可切换三种独立演算模式。每种模式保留完整流程，并单独显示当前步骤；当前步骤区域按内容调整高度。模式按钮下的介绍随选择切换，分别说明「解决什么问题、计算流程、计算取舍」。

长上下文中，逐层保存独立的主 KV、重复检索历史，会增加显存和计算开销。CSA2 将缓存共享与索引重选分开，给不同层预先配置 Full、Reindex、Reuse 角色。每层仍生成自己的主 Q、局部窗口 KV 和输出。

- **Full（6 步）**：建立后层可复用的共享起点。本图先独立演示编码器非重叠压缩，再展示解码器首个 Full：编码器输出 → 新建主 KV、索引 K → 本层索引 Q 全范围打分 → 本层 Top-2 与后层候选池 → 本层注意力输出。Full 承担建库与全域索引，主注意力仍读取选中 KV 与本层窗口。
- **Reindex（4 步）**：复用缓存，同时保留不同深度层重新选择关注内容的能力。Full 的主 KV、索引 K 与候选池 → 本层新索引 Q → 候选内重选 Top-K → 本层主 Q、局部 KV → 注意力输出。候选池限定搜索范围，Top-K 决定实际读取位置，并可传给后面的 Reuse。
- **Reuse（3 步）**：当相邻层选中位置相近时，省去重复索引。共享主 KV 与对应的最新 Top-K → 读取这些位置 → 本层主 Q、局部 KV → 新注意力权重 → 输出。省去索引 Q、索引打分和 Top-K，仍执行本层主注意力与输出投影。

每种模式都显示输入、打分、softmax（含 sink）和输出。本例 RoPE 与输出投影为单位映射，忽略量化；三种模式的最终向量分别为 `(1.1180, 0.2437)`、`(0.1811, 0.9022)`、`(-0.6985, 0.1472)`。切换模式会停止当前回放，执行、暂停、继续、上一步与重置功能均保留。

图中 CED 的全局 KV 来源和候选池检索按[技术报告](https://arxiv.org/html/2609.19969v1#S2.SS3)展示。[固定版本参考代码](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash/blob/314113f8a7dadb388215396ba5fbee2c610a04d6/inference/model.py)体现缓存与下标复用，但未显式传入 CED 的 encoder 输出支路；其索引器先计算全长分数，再屏蔽候选池之外的位置。
