# Transformer 结构学习可视化

这是一个面向初学者的 Transformer / LLM 交互式学习资料，用小型 decoder-only 模型串起输入、RMSNorm、QKV 投影、因果注意力、残差、MLP 和 LM Head。

## 页面内容

- **结构讲解页**（`transformer-structure-explorer.html`）：从完整模型进入多层 Block、单层 Block 和内部模块，了解每一步做什么、为什么这样做。
- **真实矩阵页**（`transformer-structure-explorer-matrices.html`）：使用固定教学参数实际计算各模块的输入与输出。数值默认折叠，点击矩阵标题展开或收起；名称和维度始终可见。
- 两页顶部可以相互切换，支持自动播放、暂停和“上一步 / 下一步”，同步高亮当前阶段。
- 两页的完整内容区域均限制为最大 960px、水平居中；窄屏随窗口收缩，两侧保留 16px 留白。
- 播放控件与各层级返回导航居中排列；结构讲解页的进度、步骤说明和返回工具栏与 620px 主流程节点对齐，矩阵页保留输入输出对照布局。
- 真实矩阵页可切换 Batch、样本、注意力头和高亮位置；切换查看范围时保留矩阵的展开状态。可进一步进入计算步骤和权重矩阵页面。

## 打开方式

下载整个仓库并解压，保持本目录的三个 HTML 文件在一起，双击 `transform/index.html` 即可进入结构讲解页。也可以从仓库根目录的 `index.html` 选择 Transformer 项目，或直接打开任一学习页面。GitHub 的文件预览只显示源码，需要下载后用浏览器打开。

两页使用同一个 d=8、2 个注意力头、8 词词表的未训练教学模型。结构页的完整生成示例输入 `[猫, 追, 老鼠]`，即 T=3、不含 EOS；从最后一个位置的 logits 计算完整 softmax，再做 greedy 选择。结构页下钻与生成使用同一 T=3 前缀，矩阵探索页默认 T=4，序列位置沿 T 轴，Batch 轴保存不同样本。生成的词不代表语言能力；界面显示 3 位小数，计算使用未舍入数值。

结构页的 Norm2、MLP、Add2 和层间输出均读取同一份计算 trace。改变 Batch 或层数后重新计算，不再使用各模块分别编写的示意向量。

页面不包含图片或模型权重下载。真实矩阵页完全自包含；结构讲解页的核心流程也支持离线查看。

## 计算源与导出同步

`teaching-engine.js` 是两页唯一可编辑的计算源。为了支持直接双击离线打开，两页各自内联一份该代码，结构页位于导出容器的 `data-srcdoc` 内；请勿分别修改内联副本。修改计算源后，在仓库根目录运行：

```sh
node transform/sync-teaching-engine.mjs
node transform/verify-teaching.mjs
```

同步脚本只替换 `BEGIN/END SHARED TEACHING ENGINE` 之间的计算代码，保留两页各自的交互界面。验证脚本检查残差与层间连续性、因果 mask、softmax、三 token 生成、两份导出与计算源完全一致及页面脚本语法。修改页面交互后，还应在浏览器确认完整模型 → Block → 内部模块导航、播放与窄屏布局。
